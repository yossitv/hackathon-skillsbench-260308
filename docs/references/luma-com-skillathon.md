## Description

The first agent skills hackathon. Build skills, design tasks, and benchmark your agent live. AI agents are powerful but still fail at real work - Agent Skills inject transferable procedural knowledge.

86 tasks across 11 professional domains from 180 contributors, with 80% holding PhDs or senior professional credentials.

## Tracks (5)

1. **Computer Science** - Software Engineering, Machine Learning, Cybersecurity
2. **Physical World** - Robotics, Manufacturing, Energy, Infrastructure
3. **Industry** - Healthcare, Finance, Office Suite, Insurance, Media Production
4. **Natural Science** - Physics, Mathematics, Chemistry, Biology
5. **Continual Learning** - Recursive Language Models, GEPA, Reinforcement Learning, In-Context Learning

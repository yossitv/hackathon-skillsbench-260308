# Nebula - nebula.gg Reference

Source: https://www.nebula.gg/

## Overview

Nebula is a web-based AI workforce platform that automates work through AI agents. Users describe tasks conversationally, and Nebula creates agents, builds workflows, manages files, and connects APIs — all from conversation.

## Core Capabilities

- **Agent Creation**: Automatically generates AI agents based on user instructions
- **Workflow Building**: Constructs automated processes from natural language descriptions
- **File Management**: Handles document and data organization
- **API Integration**: Connects external tools and services
- **Conversational Interface**: No coding required — uses natural language input

## Pricing

- Free tier available ($0 USD)

## Technical Details

- Built with Next.js
- Web-based application
- Responsive design with multiple theme options
